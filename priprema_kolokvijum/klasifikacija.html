Priprema teksta

en_core_web_sm je dovoljan, jer trebaju samo leme i stop reči.

Treba en_core_web_md, jer sm nema vektore reči.

nlp_pipe = spacy.load('en_core_web_sm', disable=['parser', 'ner'])

nlp_pipe = spacy.load('en_core_web_md', disable=['parser', 'ner'])

def spacy_srediTekst(doc):
    ocisceniTokeni=[]
    tokens=nlp_pipe(doc)
    for token in tokens:
        lemma_lower=token.lemma_.lower()
        if(token.is_punct or token.is_space or token.like_num or token.like_email or token.like_url):
            continue
        if token.is_stop and lemma_lower!="not":
            continue
        ocisceniTokeni.append(lemma_lower)
    return ocisceniTokeni

Funkcija prolazi kroz svaku reč komentara. Preskače interpunkciju, razmake, brojeve, mejlove i linkove. Stop reči preskače, osim not, jer not menja značenje komentara. Sve ostalo pamti kao osnovni oblik reči malim slovima, na primer ate postaje eat.

Funkciju ovde samo definišeš. Poziva je vektorizer kad pokreneš pipe.fit.

def tekst_u_vektore(tekstovi):
    vektori = []
    for tekst in tekstovi:
        reci = spacy_srediTekst(tekst)
        vektori.append(nlp_pipe(" ".join(reci)).vector)
    return np.array(vektori)

vectorizer = FunctionTransformer(tekst_u_vektore)
smote = SMOTE(random_state=RAND_STATE)

classifier = SVC(kernel='linear', C=1,
                 random_state=RAND_STATE,

                 ('resampling', smote),
                 ('classifier', classifier)])

Preciznost i odziv: kako da ih ne pomešaš

  • Preciznost: „kad kaže, da li laže?” Polaziš od onoga što je model rekao. Od svih komentara koje je model nazvao negativnim, koliki deo stvarno jeste negativan?
  • Odziv: „od svih pravih, koliko je našao?” Polaziš od stvarnosti. Od svih stvarno negativnih komentara, koliki deo je model pronašao?

U matrici konfuzije redovi su stvarne klase (True label), a kolone su predviđene klase (Predicted label). Odziv je broj na dijagonali podeljen zbirom reda. Preciznost je broj na dijagonali podeljen zbirom kolone.

  • Niska preciznost znači da model često stavlja tu klasu tamo gde ne pripada, kao lažna uzbuna.
  • Nizak odziv znači da model propušta mnogo komentara te klase.

Ostalo iz izveštaja

  • F1: jedan broj koji spaja preciznost i odziv. Visok je samo kad su oba visoka.
  • support: koliko komentara te klase ima u testu.
  • accuracy: udeo svih tačno pogođenih komentara. Kad su klase neravnomerne, ovaj broj vara: model koji uvek kaže pozitivan već ima visok accuracy.
  • macro avg: običan prosek preko klasa, gde svaka klasa vredi isto. Pokazuje kako prolazi i retka klasa neutralan.
  • weighted avg: prosek u kom česta klasa vredi više, srazmerno svom support. Zato je obično viši od macro.
  • balanced accuracy: prosek odziva svih klasa, isto što i macro recall. Sa adjusted=True nasumično pogađanje daje 0, a savršen model 1. U materijalima se negde koristi adjusted=True, a negde ne. Ovde je bez toga.

Kako tumačiš: ako je weighted F1 mnogo veći od macro F1, model dobro radi na čestim klasama, a loše na retkoj.

def get_model_metrics(y_true: np.ndarray, y_pred: np.ndarray, model_name: str):
    report = metrics.classification_report(y_true, y_pred, output_dict=True)
    macro_avg = report['macro avg']
    weighted_avg = report['weighted avg']
    return {
        'Model': model_name,
        'Macro Precision': macro_avg['precision'],
        'Macro Recall': macro_avg['recall'],
        'Macro F1-Score': macro_avg['f1-score'],
        'Weighted Precision': weighted_avg['precision'],
        'Weighted Recall': weighted_avg['recall'],
        'Weighted F1-Score': weighted_avg['f1-score'],
        'Balanced Accuracy': metrics.balanced_accuracy_score(y_true, y_pred)
    }

Podešeni model je malo bolji po svim globalnim metrikama: macro F1 0.635 naspram 0.622, a weighted F1 0.712 naspram 0.692. Najbolji su rbf kernel i C=10. Klasa neutralan i dalje ostaje najslabija.

Podešavanje ne mora da popravi model. U profesorkinom rešenju razlika je takođe zanemarljiva, a u varijanti TF-IDF je ovde test rezultat čak neznatno niži. Napiši šta se desilo i ne izmišljaj poboljšanje.

Ako se u zadatku traži poređenje, ovo su macro F1 vrednosti podešenih modela: TF-IDF + LR 0.678, vektori + SVM 0.635, BoW + stablo 0.631.

Dodaci koji mogu da se pojave

Ovo ubacuješ u glavni tok kad zadatak to traži. Kod je proveren na uzorku od 600 komentara.

Numerička kolona uz tekst

Kad uz tekst koristiš numeričku kolonu. RobustScaler je dovodi u sličan opseg sa ostalim atributima. Isti obrazac je u svesci sa vektorima reči. Tada X mora biti DataFrame, a ne jedna kolona.

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import RobustScaler

data['review_len'] = data['review'].str.split().str.len()
X = data[['review', 'review_len']]

column_transformer = ColumnTransformer([
    ('text', TfidfVectorizer(tokenizer=spacy_srediTekst, token_pattern=None,
                             max_features=1500), 'review'),
    ('scaling', RobustScaler(), ['review_len'])
])

pipe = Pipeline([('data_transform', column_transformer),
                 ('classifier', LogisticRegression(max_iter=2000))])
pipe.fit(X, data['sentiment'])

# ime hiperparametra sada ima jedan nivo vise:
pipe.set_params(data_transform__text__max_features=1000)

Samo imenice, pridevi i glagoli

Zadatak iz Bloka 1. Treba ti token.pos_. Menjaš samo funkciju čišćenja, a ostatak toka ostaje isti.

def spacy_srediTekst(doc):
    ocisceniTokeni=[]
    tokens=nlp_pipe(doc)
    for token in tokens:
        if token.pos_ in ('NOUN', 'ADJ', 'VERB'):
            ocisceniTokeni.append(token.lemma_.lower())
    return ocisceniTokeni

print(spacy_srediTekst('The tiny burger was cold but the staff smiled'))

Novi atributi iz spaCy-ja

Zadatak iz Bloka 1. Ovde je učitan pun model, jer len(doc.ents) traži NER. Na uzorku negativni komentari imaju više imenica, glagola i interpunkcije, jer su duži. Značajnost proveravaš poređenjem proseka ili box plotom.

nlp_full = spacy.load('en_core_web_sm')     # treba nam i NER

def count_features(text):
    doc = nlp_full(text)
    return pd.Series({
        'n_noun': sum(t.pos_ == 'NOUN' for t in doc),
        'n_verb': sum(t.pos_ == 'VERB' for t in doc),
        'n_ent': len(doc.ents),
        'n_punct': sum(t.is_punct for t in doc)
    })

features = data['review'].apply(count_features)
print(features.join(data['sentiment']).groupby('sentiment').mean().round(2))
